California Housing Data Exploration

Project Overview

This project performs exploratory data analysis (EDA) on the California Housing dataset using Python.

The notebook demonstrates common data science tasks including:

* Data loading
* Data cleaning
* Missing value handling
* Duplicate detection
* Outlier treatment using the IQR method
* Statistical summaries
* Data visualization
* Correlation analysis

The goal is to better understand the factors that influence California housing prices.

Key Findings

* Median income has the strongest positive correlation with housing prices.
* Total rooms and population show weaker relationships.
* The dataset required handling missing values and checking for duplicates before analysis.
